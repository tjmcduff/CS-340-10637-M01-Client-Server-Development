# CS-340-10637-M01-Client-Server-Development

How do you write programs that are maintainable, readable, and adaptable?
To write maintainable, readable, and adaptable programs, I focus on clear naming conventions, modular structure, and concise, well-commented code. A strong example of this is my CRUD Python module from Project One. I designed it as a reusable interface for interacting with a MongoDB collection, which later powered the dynamic data displayed in my dashboard during Project Two. This separation of concerns made it easier to update the logic in one place without affecting the rest of the project. In the future, I could reuse this same CRUD module in other applications that need a MongoDB backend — for example, an inventory system, a customer service portal, or a logging tool.

How do you approach a problem as a computer scientist?
When solving problems, I take a step-by-step, data-driven approach. For the Grazioso Salvare dashboard, I started by understanding the client’s needs: they wanted a live dashboard to analyze animal shelter data, filter by breed and outcome, and visualize locations. I broke the project into smaller parts — designing database queries, building CRUD functionality, and then linking those queries to interactive dashboard components. Compared to previous courses, this project felt more realistic and end-to-end. I had to think not just about code, but about user experience, modularity, and real-world application. In the future, I’d continue using this strategy — breaking down the requirements, building reusable tools, and iteratively testing and improving the product.

What do computer scientists do, and why does it matter?
Computer scientists solve complex problems using logic, code, and data. They build systems that help organizations make informed decisions, operate efficiently, and scale effectively. In this project, my work directly supported a fictional company, Grazioso Salvare, by helping them track adoptable animals, view key outcomes, and filter for specific data like breed or rescue suitability. A dashboard like this could help their team save time, deploy resources more strategically, and ultimately rescue more animals. This kind of impact — using tech to make lives better — is why computer science matters to me.
